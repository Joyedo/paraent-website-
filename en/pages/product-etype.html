Features

4 Key Advantages of E-TYPE

An economical digital power regulator with all essential features, nothing missing

✨

Attractive — Economic Design

Compact and elegant design engineered for easy wiring and use. Efficient installation even in limited spaces.

🔔

Basic — Full Standard Alarms

All basic alarm functions including over-current, heatsink overheat detection, load break, SCR element fault, load imbalance. Alarm message display via LED, soft start and current limiting functions standard.

🔄

Comprehensive — Dual Control

Compatible with both zero-crossing and phase angle control, allowing customers to switch based on load type. Test mode allows testing with a small load instead of the actual load.

💻

Digital — Digital Computation Control

Stable control through microprocessor-based digital computation. Compatible with both resistive and inductive loads.
