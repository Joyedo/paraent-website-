Features

4 SMART Core Technologies

The next-generation flagship power regulator integrating all of Paraent's power regulator technologies

01 Patented

SMART MPD

The Max Power Distribution Control function smooths main power by distributing power among multiple power regulators when controlled with zero-crossing. Improves power factor and reduces peak power.

02 Patent #10-1405243

SMART PLF

When multiple parallel loads are connected to a single power regulator, this function detects partial load open circuits. Auto-tuning acquires load characteristic patterns for accurate detection.

03 Color LCD · 18-Key Pad

SMART DISPLAY (PSD)

Improved user interface with color LCD and 18-key pad. Enables self-diagnostics, test mode, easy parameter settings. Can be attached to the unit or mounted separately on a panel.

04 Combined Control

SMART COMBINATION

Saves cost and space by mounting up to 3 single-phase power regulators in one body. Supports various wiring methods including single-phase, three-phase, 1P1L, 1P2L, 1P3L, 3P3L, etc.

RS-485 · Modbus-RTU Communication

Up to 32 units in multi-drop network configuration. Communication speed up to 115,200bps for standard integration with PLC, SCADA, HMI. Equipped with 32-bit CPU for high-speed, high-precision calculation.

SMART PLF (Partial Load Failure Detection)

(Patent No. 10-1405243: Power regulator with partial load failure detector and detection method)

- Detects partial load open-circuits when multiple parallel loads are connected to a single power regulator.

- Auto-tuning acquires load characteristic patterns to achieve accurate partial load failure detection.

SMART DISPLAY (PSD — PARA SMART DISPLAY)

- Improved user interface with color LCD and 18-key pad.

- Self-diagnostics, test mode, and easy parameter settings for improved user convenience.

- PSD can be attached to the unit or mounted separately on the front panel for better visibility.

PSD (PARA SMART DISPLAY)

- Displays voltage / current / power / resistance (temperature: optional) and cycles through parameters for each phase.

- Graphically displays input and output values for enhanced real-time visibility.

- The display unit is detachable; when mounted on the panel front, there is no need to install separate ammeters or voltmeters.

SMART COMBINATION

- Up to 3 single-phase power regulators in one body, each controlled by its own input signal. Compatible with all heater wiring configurations.

- When using 1 single-phase unit

- When using 2 single-phase units

- Controlling 2 phases for a single-phase heater

- Three-phase 2-LEG (zero-crossing only)

- Improved stability

- Improved economy

- When using 3 single-phase units

- Three-phase 4-wire system

- Three-phase 3-LEG (Star and Delta wiring)

- Open Delta wiring

- Accepts individual input signals or controls all 3 units with a single input signal

SMART COMBINATION — Alarm Functions

- Each alarm can be routed to one of 3 relays per user selection.

- User selects whether output is cut off when an alarm triggers.

- Fan speed driven by heatsink temperature as specified by user to extend fan life.

- Warning and alarm thresholds for heatsink overheat set at user-defined temperatures.

- Alarm types:

① Over-current  ② Fuse open  ③ Heater open  ④ Heatsink overheat  ⑤ SCR element fault  ⑥ Load imbalance  ⑦ Main power cutoff  ⑧ FAN fault  ⑨ Frequency noise  ⑩ PLF (Partial Load Failure)

SMART Communication

- Communication type: RS-485 2-wire half-duplex

- Communication speed: 4800, 9600, 19200, 38400, 57600, max 115,200bps

- Max connection: 32 units

- Protocol: Modbus-RTU

- READ & WRITE operations via communication

- USER INTERFACE provided

SMART Self-Diagnostics
SMART Test Mode

Powerful 32-bit CPU (12-bit ADC) delivers fast computation and response for optimal control performance.

With power and load connected, checks current parameter values, alarms, and signal wiring status.

When testing with the actual load is difficult, connects a small load to verify output status without the real load.
